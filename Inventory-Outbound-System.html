Email Auto-Send Setup (EmailJS)

Lets "Out of Delivery" and the per-destination ✉️ button in Trip Details send an email straight away, with no extra click needed — using a free EmailJS account connected to your own Gmail. One-time setup:

1. Go to emailjs.com and sign up free.
2. Email Services → Add New Service → connect your Gmail → copy the Service ID.
3. Email Templates → Create New Template. Set "To Email" field to {{to_email}}, "Subject" to {{subject}}, and put {{message}} somewhere in the body → copy the Template ID.
4. Account → General → copy your Public Key.
5. Paste all three below and Save.

Delivery Status

Every DO that's reached "DO Issued" on the Progress Board, tracked across its full journey: "DO Issued" (printed, no trip/driver yet), "Scheduled" (trip + driver assigned, not dispatched), "Out of Delivery" (driver already left), or "Delivered" (Completed) under Operation Fleet -> Trip Schedule. Once a DO is dispatched it moves out of the "DO Issued" column on the Progress Board and is tracked here instead. This is a read-only record; nothing here can be dragged or edited.

Pickers

Add one picker at a time (press Enter or click "+ Add Picker"). Registered pickers show up as a dropdown when assigning picker(s) to an STO — no need to type names each time. Target is auto-calculated: the overall Picker Daily Target above (Weekday/Weekend) split evenly across every registered picker — it updates automatically as pickers are added/removed or the overall target changes. "Today (pcs)" counts pieces from STOs assigned to that picker today and resets to 0 automatically the next day.
Unsaved changes — click Save before leaving this tab.

Rollcages / Trolleys

Registered rollcages show up as a dropdown when an STO is dragged into Packing. Each one can only be assigned to one STO at a time — it frees up automatically once that STO moves on to Packed (or gets dragged back out of Packing).
Unsaved changes — click Save before leaving this tab.

Packing Stations

Registered stations are used to auto-assign STOs when they enter the Packing stage — each STO rotates to the next station in the list (round-robin). You can still change a card's station manually afterward. Target is auto-calculated: the overall Packer Daily Target above (Weekday/Weekend) split evenly across every registered station — it updates automatically as stations are added/removed or the overall target changes. "Today (pcs)" counts only pieces assigned to that station today and resets to 0 automatically the next day. Shift Start/End is optional — leave both blank for a station that's always on. Outside its shift window, a station is skipped by auto-assign and hidden from the manual picker (it stays selectable only if it's already assigned to that STO).
Unsaved changes — click Save before leaving this tab.

Receive Stations

Registered stations show up when assigning who's receiving an incoming STO (dragging a card into "On Progress" on the Inbound Progress Board). Target is auto-calculated: the overall Inbound Daily Target above (Weekday/Weekend) split evenly across every registered station — it updates automatically as stations are added/removed or the overall target changes. "Today (pcs)" counts only pieces that finished receiving (moved to Complete) at that station today and resets to 0 automatically the next day. Shift Start/End is optional — leave both blank for a station that's always on. Outside its shift window, a station is hidden from the picker (it stays selectable only if it's already assigned to that STO).
Unsaved changes — click Save before leaving this tab.

Drivers

Unsaved changes — click Save before leaving this tab.

Admin Password (Operation Fleet)

Once a trip's date is in the past, it becomes a locked log — editing it (moving its card, changing driver/destination/DO, plate no., deleting it, or scheduling a brand-new trip for that day) needs this Admin password first. Leave this blank to leave past dates unlocked (no change from before). This is a soft lock stored in this browser only, same as driver passwords — not real server-side security.

Users & Access (Login)

Each staff logs in with their own username & password, and only sees the tabs you tick for them below. Admin/Team Lead accounts always have full access to everything, including this page. Team Setup itself is always Admin-only — it's not one of the toggle-able tabs. This login is stored in this browser only, same as the other passwords in this app — a soft access-control layer, not real server-side security.

Cloud Sync (Firebase)

Every staff's computer shares the same STO/DO/Fleet/Inbound/Users/settings data automatically through one shared Firebase database — no setup needed per computer, it just connects on its own. Changes made on any computer show up on the others within about a second.

STO From Boutique Alert Thresholds

Applies to every boutique the same way — no per-boutique setup. An STO From Boutique turns Warning once it's waited this many days since being issued, and Critical once it passes the second number. Changes apply immediately.

Garment Order Alert Thresholds

Separate from STO From Boutique above. A batch turns Warning/Critical based on days since its Order Date, and stops counting (shows "Done") once every SKU inside it is fully received. Changes apply immediately.
